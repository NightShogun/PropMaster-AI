# Marine Propeller Advisor Web App

Static browser version of the existing Tkinter app.

## Run

Open `index.html` in a browser.

For a local URL instead:

```bash
cd ..
python3 -m http.server 8000
```

Then open `http://127.0.0.1:8000/web_app/`.

The app reads the existing `photos/` and `videos/` folders from the project root.
